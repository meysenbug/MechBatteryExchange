# Mech Battery Exchange

RimWorld 1.6＋Biotech用。小型・大型の交換ステーションに内部バッテリーを3本備え、同機種の管理下メカが短時間で交換できます。

## 導入

1. Steam Workshopでサブスクライブするか、手動導入の場合は `MechBatteryExchange` フォルダをRimWorldの `Mods` に配置します。
2. MOD設定で Harmony → Core → Biotech → Mech Battery Exchange の順に有効化し、再起動します。
3. 既存セーブへ追加できます。通常充電器やメカを自動変換しません。

## 使い方

- 基礎メカ技術／標準メカ技術の研究後、Biotech建築メニューで小型／大型交換ステーションを建築します。
- 電力網へ接続し、建物の「スロット設定」から、マップ上にいる管理下メカの機種を割り当てます。
- 最初は空です。3本のうち残量が最も多い1本ずつ充電します。同率なら先のスロットを優先します。
- 既存の充電開始設定に従って、満充電の同機種バッテリーがあれば通常充電より交換を優先します。
- 小型は3秒、大型は6秒で交換します。在庫切れ・設備使用中・到達不能の場合は通常の補給へ戻ります。
- 「利用禁止」は交換だけを停止します。充電も止める場合は電源をOFFにします。
- 運搬役を1人選び、電力切れで強制休眠中の管理下メカを右クリックして「交換ステーションに運ぶ」を選びます。同機種の満充電バッテリーが必要です。通常充電器への運搬も選べます。
- 廃棄物満杯でも満充電バッテリーの交換は可能です。廃棄物を搬出すると充電が再開します。
- 機種変更・割当解除は対象スロットの残量を失います。解体時も内部バッテリーはドロップしません。

## 設備

| 項目 | 小型 | 大型 |
|---|---|---|
| サイズ | 3×1 | 3×2 |
| 重量区分 | Light | Medium / Heavy / UltraHeavy |
| スロット数／同時充電数 | 3／1 | 3／1 |
| 消費電力 | 200W | 400W |
| 建築費 | スチール250・コンポーネント4 | スチール500・コンポーネント8 |

## 制限

満充電時も所定電力を消費します。アンインストール・持ち運び、キャラバン補給はありません。
標準のエネルギーと重量区分を使う追加メカは対象になりますが、個体依存の独自充電計算を持つ他MODは対応保証外です。
MOD取り外しの自動移行はありません。

## 更新内容（2026-11-03）

帯域コストが1を超える機種で、内部充電の廃棄物係数が過少になる不具合を修正しました。Scytherは満充電あたり5ではなく10個相当を基準に計算します。既存の残量・保存済み端数は維持し、過去の不足分を遡って追加しません。

廃棄物は仕様の実充電増分に比例して計算します。バニラの固定tick量・float累算とは小さな丸め差があり、総量のビット単位の一致は保証しません。

## 自動交換版の検証結果（2026-11-16）

RimWorld 1.6.4871 rev591＋Biotechで、仕様のT01〜T23を各項目の検証範囲で確認しました。当時の版を既存セーブに追加して通常充電が継続することと、検証用MODなしで小型・大型とも自動交換することを確認しました。

- **通常充電との比較（T05）** — 対応22機種の廃棄物係数を照合し、4重量区分の代表6機種で半充電・全充電を比較しました。搬出待ちのない区間の充電時間と電力積算は一致し、満杯停止・通常搬出・充電再開も確認しました。廃棄物量の差は、本MODの実充電増分とバニラの累算を独立に再計算して照合しました。
- **表示（T23）** — 1280×800・標準UI倍率で、小型・大型の日本語と英語の設定画面、残量破棄の確認文を確認しました。
